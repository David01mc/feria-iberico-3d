# La Hora del Vermut · puesto pequeño

Barra de aperitivo inspirada en las referencias aportadas: estructura de pino con bombillas,
toldo azul y crema, botellas alineadas y vermut servido con naranja y aceituna.

|               |                                 |
| ------------- | ------------------------------- |
| Parcela       | D-56 · x 25 … 28, z 2 … 5       |
| Tipo          | Lineal pequeño · 3 × 3 m        |
| Frente        | Norte, hacia la Avenida Central |
| Altura máxima | 3,5 m                           |

El mostrador de pino deja espacio para trabajar por detrás. La pared de fondo y los dos
laterales están retranqueados 6 cm respecto a los límites compartidos, para evitar parpadeos
con el stand de aceitunas y los módulos vecinos. El paseo tiene colisión con las paredes y la
barra.

Se aprovechan las texturas existentes de pino, madera oscura y lino. Las botellas, vasos,
naranja y aceitunas están construidos con geometría sencilla en `VermutDrinks.tsx`, sin
descargar recursos adicionales.
